## 架构事实与不可改变的外部契约

- CLI main → options（解析）/commands（执行）→ FilePipeline → StreamProcessor → CipherCtx → AES/GHASH；FilePipeline → 私有 OutputTransaction。
- AES fast 门面 → AES-NI 或 bitslice → GF；AES-NI 软件回退 → 标量 AES。按职责拆分的调用链保留，不能把源码目录互相引用直接判作运行时循环。
- API、符号、布局和文件字节格式不变；仅 AES-128、CTR/GCM、96 位 nonce、空 AAD、128 位标签。CTR 原始密文；GCM 密文后附标签。
- 流式解密输出为候选明文；一次性解密和文件解密认证成功才发布。保留容量检查、长度限制、finish 幂等、结束后拒绝处理、回调快照、重入拒绝与失败回滚。
- 稳定普通输入和可信输出目录、单对象非并发为现有前置条件。目录竞争、崩溃恢复、其他算法/AAD/并行不属于已实现能力，不作为凭空新增需求。
